# Roadmap

Intenciones, no promesas. Es un proyecto pequeño con una sola persona detrás.

## Antes de la primera versión pública
- [x] Flujos exportados como JSON importable, sin credenciales ni IDs personales.
- [x] Configuración en un solo lugar (nodo `config`).
- [x] Sin horario diario por defecto.
- [ ] Capturas sin datos personales.
- [ ] Instalación probada desde cero en un n8n limpio.

## Después
- [ ] Prueba automática que verifique que el código de los flujos coincide con `src/`.
- [ ] Traducción al inglés.
- [ ] Integración continua (pruebas en cada cambio).
- [ ] Plantillas de issues y código de conducta.

## Ideas abiertas (ayuda bienvenida)
- [ ] Alternativa a Google Sheets (CSV, base SQL o Airtable).
- [ ] Alternativa a Telegram (correo, WhatsApp).
- [ ] Otros proveedores de modelo para la decisión.
- [ ] Más casos de ejemplo (temporada alta, producto nuevo, proveedor que falla).
